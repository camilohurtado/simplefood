# Changelog

Todos los cambios relevantes de SimpleFood se documentan en este archivo.
Formato basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y versionado [SemVer](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-10 — Línea base

### Agregado
- Estructura del proyecto Maven (Java 21) y convenciones de código.
- Módulo de autenticación con roles cliente, mesero y administrador.
- Módulo de menú digital con CRUD de platos y categorías.
- Módulo de pedidos con máquina de estados y notificación en tiempo real.
- Módulo de reservas por fecha y hora con asignación de mesa sin cruces.
- Módulo de caja: reporte de ventas diario y cierre de caja.
- Servidor web embebido con API REST, eventos SSE e interfaz básica.
- Pruebas unitarias por módulo y pruebas de integración de la API.
- Documentación: README, estructura de base de datos y manual de despliegue.
